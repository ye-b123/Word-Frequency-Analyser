# WordFrequencyAnalyser

A Python-based tool that analyses text and calculates word frequencies.



&#x20;Word Frequency Analyser



A beginner-friendly Python project that analyses text and identifies how frequently words appear.



This project is part of my journey into Python programming and Natural Language Processing (NLP).



&#x20;About the Project



The Word Frequency Analyser takes user-provided text, processes it, and calculates the frequency of individual words. It presents the results to help users understand patterns in text.



&#x20;Features



\- Accepts user-provided text

\- Analyses word frequency

\- Identifies frequently occurring words

\- Provides a simple, interactive experience



&#x20;Technologies Used



\- Python

\- Python string manipulation

\- Text processing



&#x20;Getting Started



&#x20;Prerequisites



Ensure you have Python 3 installed.



Check your Python version:



```bash

python --version

```



&#x20;Installation



1\. Clone this repository:



```bash

git clone https://github.com/ye-b123/Word-Frequency-Analyser.git

```



2\. Navigate to the project folder:



```bash

cd Word-Frequency-Analyser

```



3\. Run the program:



```bash

python FrequencyCounter.py

```
